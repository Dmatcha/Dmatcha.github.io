PART 1: ACQUISITION & INSTALLATION

Physical Checklist

Before diving into software, ensure you have everything physically prepared:

  • USB Flash Drive (8GB minimum) - This will become your Windows installation/reload drive
  • Stable Internet Connection - For downloading the Media Creation Tool and drivers
  • Backup Storage - External drive or cloud storage for important files

Specifically about USB flash drives:

  • USB 3.0 or higher recommended for faster read/write speeds
  • 8GB minimum for Windows 10, 16GB for Windows 11
  • SanDisk, Samsung, or Kingston reliable brands suggested

Windows Media Creation Tool and You

Accessing Windows to Make Windows

To create a Windows installation/reload USB drive, we will use Microsoft's official Media Creation Tool.

Important

Always use official Windows sources from Microsoft. Never download Windows ISOs from third-party websites.

  1. Navigate to Microsoft's official Windows download page
  2. Download the Media Creation Tool for your desired Windows version
  3. Run the tool with administrator privileges
  4. Select "Create installation media (USB flash drive, DVD, or ISO file)"
  5. Choose your language, edition, and architecture (64-bit recommended)
  6. Select your USB flash drive from the list
  7. Wait for the download and creation process to complete
  8. Your Windows installation USB is ready!
Success

You now have a Windows 10/11 Reload USB drive ready for installation!

Installation and User Account Creation

Installation Procedure

Getting to the install screen

  1. Insert your newly created Windows USB into the target computer
  2. Power on and enter the Boot Menu (usually F12, F11, or F2 depending on manufacturer)
  3. Select the USB drive as the boot device
  4. Windows will begin loading from the USB
  5. On the first screen, select your language preferences
  6. Click "Install Now"
Warning

If you are installing over an existing system, this will ERASE all data on the selected drive. Ensure you have backups!

Proceeding through Installation

  1. Enter your Windows product key (or skip if using Home edition)
  2. Accept the license terms
  3. Select "Custom: Install Windows only (advanced)" for a clean install
  4. Select the drive where you want Windows installed
  5. Wait for files to copy and installation to complete
  6. The system will restart automatically

First time user setup

  1. Configure region and keyboard layout
  2. Connect to WiFi or Ethernet
  3. Review privacy settings (configure according to your preferences)
  4. Create your user account and password
  5. Wait for final setup to complete
  6. You'll see the Windows desktop for the first time!

PART 2: INITIALIZATION

This section covers the post-installation setup steps for your Windows system.

START

TAKE YOUR TIME. Read everything Microsoft prompts you with.

Updates and Updating

Overview: First half is about initial updates after fresh installing Windows. Second half is what to do after and can be repeated for subsequent updates.

Upon hitting the desktop for the first time

First you'll need to connect to the internet. If your system has a LAN port, connect it to your router via RJ45 cable. Otherwise use WiFi. Select your network (preferably 5GHz), input your password.

Next, head to Windows Settings > Updates & Security. Click check for updates. Wait for all updates to download and install—some may require a reboot. After rebooting, check for updates again. Once you no longer have any updates remaining, reboot your system.

After Windows Updates Completed -> Update Drivers Using Device Manager

Your system will likely still be missing many key drivers. Right-click the Windows icon or press Windows key + X and select Device Manager. Open each tree branch and right click each entry, select "update driver" then "Search automatically". If a new driver is found the system will attempt to install it.

Info

While this method is tedious, it is the safest way to update drivers, and the drivers themselves are typically the most stable (DCH) versions.

Warning

Avoid driver-updating software, as they are overwhelmingly malware.

Checking for updates manually

Your laptop manufacturer or PC component OEM should have more up-to-date drivers. Write down the manufacturer for each major hardware component:

For Laptops:

  • Major Manufacturer (e.g. Acer, Asus, Gigabyte, MSi)
  • Internet Port (e.g. Intel, Realtek, Killer)
  • WiFi chip (e.g. Intel, Broadcom, Qualcomm)
  • Mainboard chipset
  • Graphics (e.g. Intel, nVidia, AMD)

For PCs:

  • Motherboard
  • GPU
  • Network

Drivers and OEM Software

OEM stands for Original Equipment Manufacturer. OEM drivers are available on the manufacturer's support page. Download the latest drivers for your specific model to ensure optimal performance and stability.

Advanced CPU Settings

Using the Registry Editor, we will enable advanced control features for the CPU that are hidden by default.

WARNING

Absolutely do not proceed unless you are willing to risk damage to your data or hardware.

Opening Registry Editor

Press Windows key + R to bring up Run. Type regedit and press Enter.

Quality of Life

Enable numpad on startup

  1. Open HKEY_USERS\.Default\Control Panel\Keyboard
  2. Double click InitialKeyboardIndicators
  3. Change the value to 2
  4. Click OK

Performance Enhancement

Allowing the computer to relax [UNLOCK CORE PARKING FEATURES]

Unlocking this feature allows your PC to use less power when not doing stressful tasks. It also allows the CPU to boost higher.

  1. Navigate: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power\PowerSettings\54533251-82be-4824-96c1-47b60b740d00\0cc5b647-c1df-4637-891a-dec35c318583
  2. Double-click Attributes and change value to 2
  3. Open Power Options > Change advanced power settings
  4. Configure Processor power management > Processor performance core parking

Advanced GPU Settings

Only the settings in the Intel, nVidia, and AMD graphics control panel will be shown here. No overclocking will be covered.

Identifying your Graphics Processing Unit

Open Device Manager > Display adaptors. Make a note of which you have:

  1. Intel iGPU (UHD series)
  2. NVIDIA GeForce series
  3. AMD Radeon series

Then prepare to interact with your corresponding control software:

  • Intel graphics command centre
  • nVidia Control Panel
  • AMD Catalyst / Radeon Software

Cloning SSDs using dd in macOS

If you're a macOS enthusiast and need to clone your Windows boot SSD, here's the power of dd.

  1. Plug in your SSDs into an enclosure or connect to macOS
  2. Open diskutil, select view > show all devices
  3. Note the disk numbers for source and target
  4. Open terminal WARNING this is where you can mess up
  5. Use: sudo dd if=/dev/rdiskS of=/dev/rdiskT bs=4M
  6. Replace S with source disk number, T with target disk number
  7. This will take a very long time! There is no loading bar.

Obscure CLI Disk Clone

Migrating an SSD? Upgrading your OS? Avoid reinstalling everything!

1. Specifics

  • One blank disk
  • One (or more) data disks
  • macOS or Linux
  • External disk readers
  • Patience
WARNING

If you have valuable data, make sure you have a copy. We will do things that will ruin your life if something goes wrong!

2. Yahoo!

  1. Plug in the blank, empty disk
  2. In macOS, load up Disk Utility, set view to show all devices
  3. Write down the disk numbers for source and target
  4. Unmount the subcategory disks
  5. Use this command: sudo dd if=/dev/rdiskX of=/dev/rdiskY bs=1m

3. Why the heck would anyone do this?

Sometimes you need to migrate an OS to a different slot, or you have a faulty system and need to clone before it dies completely.

ICONS

Customize drive icons in Windows Explorer for easier identification.

Network Disk Icon

Mapping a network drive? Bored of the default icon? Let's do it!

Note

We will dive into regedit so backup anything important!

  1. Open regedit as administrator
  2. Browse to: HKEY_CURRENT_USER\Software\Classes\Applications\Explorer.exe\Drives\
  3. Create a new key with your drive letter (e.g., "S")
  4. Create DefaultIcon key under it
  5. Set the default value to your .ico file path
  6. Close regedit and refresh Explorer

USB Drive Icon

Wanna spice up your old basic USB drive? Let's add some pizzazz!

Checklist

  • USB Drive
  • .ico file
  • Basic text editor

Pizzazz

  1. Plug in the USB
  2. Copy your .ico file to the USB root
  3. Create a file named autorun.inf with: 
    [autorun]
icon=ABCXYZ.ico
  4. Replace ABCXYZ with your icon filename
  5. Eject and reconnect the USB

Tool 03: Peak Retro

Linux-only

I've only used this in Linux. You will need "mkvtoolnix-cli" and "video2x.AppImage" and maybe additional libraries depending on your Linux distribution.

Description

Useful for ancient 480(p) files. Upscale old videos from ancient NTSC media.

STEP 1: Create A Clean CFR Video Intermediate

This stabilizes timestamps and converts the source into a clean constant-framerate intermediate before AI processing. Audio is intentionally excluded to avoid Video2X muxing and timestamp bugs.

ffmpeg -i "EP01.mkv" -fps_mode cfr -r 30000/1001 -c:v libx264 -crf 18 -preset slow -an "EP01_CFR.mkv"

STEP 2: AI Upscale Using RealESRGAN Anime Video v3

This performs the actual AI upscale on the GPU using the anime-optimized RealESRGAN model. The output remains video-only for maximum stability.

/Path2File/Video2X-x86_64.AppImage --no-copy-streams -d 1 -i "EP01_CFR.mkv" -o "EP01_UPSCALE.mkv" -p realesrgan --realesrgan-model realesr-animevideov3 -s 2

STEP 3: Compress The Upscaled Video To HEVC Using x265

This uses CPU-based x265 encoding for superior compression efficiency, lower remote-streaming bandwidth, and better anime quality retention than NVENC HEVC.

ffmpeg -i "EP01_UPSCALE.mkv" -map 0:v -c:v libx265 -crf 20 -preset slow -pix_fmt yuv420p -x265-params "aq-mode=3:aq-strength=1.0:deblock=-1,-1" "EP01.hevc"

STEP 4: Convert Original Audio Tracks To AAC

This converts both original audio tracks into modern AAC audio for improved Jellyfin compatibility, browser playback, and seeking stability.

ffmpeg -i "EP01.mkv" -map 0:a:0 -map 0:a:1 -c:a aac -b:a 192k "EP01_AUDIO.mkv"

STEP 5: Build The Final MKV

This creates the final MKV using: HEVC video, converted AAC audio, original subtitle tracks, rebuilt MKV indexes/cues. The result should seek properly and switch audio tracks reliably.

mkvmerge --engage no_cue_duration --engage no_cue_relative_position -o "EP01_FINAL.mkv" --aspect-ratio 0:16/9 "EP01.hevc" --no-video "EP01_AUDIO.mkv" --no-video --no-subtitles "EP01.mkv" --no-video --no-audio

Usage

Use this to test single-file conversions. Replace "EP01" with the actual filename (and location) of your videos.

Batch Processor

This is the same as the above but in a batch-convert code. Create the script inside the folder with all the videos you want to upscale. The Video2x.Appimage should be placed in the folder above this, and made executable via chmod +x. (example: Projects/Video2x.Appimage, Projects/UpscaleMe/"script and video files here") 

#!/usr/bin/env bash

# ============================================================
# Portable Anime AI Upscale Pipeline
# ============================================================

set -euo pipefail

# ---------- PATH SETUP ----------
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_DIR="$(dirname "$SCRIPT_DIR")"

V2X="$PROJECT_DIR/Video2X-x86_64.AppImage"
LOG="$SCRIPT_DIR/upscale_batch.log"

# ---------- SETTINGS ----------
X265_CRF="20"
X265_PRESET="slow"
UPSCALE_FACTOR="2"

# ---------- START LOG ----------
echo "" | tee -a "$LOG"
echo "==================================================" | tee -a "$LOG"
echo "Batch Started" | tee -a "$LOG"
date | tee -a "$LOG"
echo "==================================================" | tee -a "$LOG"

# ---------- CHECK VIDEO2X ----------
if [ ! -f "$V2X" ]; then
    echo "ERROR: Video2X AppImage not found:" | tee -a "$LOG"
    echo "$V2X" | tee -a "$LOG"
    exit 1
fi

# ---------- GPU DETECTION ----------
GPU_ID=$("$V2X" --list-devices 2>/dev/null | grep -iv "intel\|integrated" | head -1 | awk '{print $1}' | tr -d '.')

if [ -z "$GPU_ID" ]; then
    echo "ERROR: No discrete GPU detected." | tee -a "$LOG"
    exit 1
fi

echo "Using GPU device index: $GPU_ID" | tee -a "$LOG"

# ---------- MAIN LOOP ----------
for ORIG in "$SCRIPT_DIR"/*.mkv; do

    [ -e "$ORIG" ] || continue

    BASE=$(basename "$ORIG" .mkv)

    CFR="${SCRIPT_DIR}/${BASE}_CFR.mkv"
    UPSCALE="${SCRIPT_DIR}/${BASE}_UPSCALE.mkv"
    HEVC="${SCRIPT_DIR}/${BASE}.hevc"
    AUDIO="${SCRIPT_DIR}/${BASE}_AUDIO.mkv"
    FINAL="${SCRIPT_DIR}/${BASE}_FINAL.mkv"

    echo "" | tee -a "$LOG"
    echo "==================================================" | tee -a "$LOG"
    echo "Processing: $BASE" | tee -a "$LOG"
    date | tee -a "$LOG"
    echo "==================================================" | tee -a "$LOG"

    # ---------- SKIP COMPLETED ----------
    if [ -f "$FINAL" ]; then
        echo "Skipping: FINAL already exists." | tee -a "$LOG"
        continue
    fi

    # ============================================================
    # STEP 1 — CFR NORMALIZATION
    # ============================================================

    echo "--- Step 1: CFR Normalize ---" | tee -a "$LOG"

    nice -n 10 ffmpeg -y -i "$ORIG" -fps_mode cfr -r 30000/1001 -c:v libx264 -crf 18 -preset slow -an "$CFR"

    # ============================================================
    # STEP 2 — AI UPSCALE (GPU)
    # ============================================================

    echo "--- Step 2: AI Upscale ---" | tee -a "$LOG"

    "$V2X" --no-copy-streams -d "$GPU_ID" -i "$CFR" -o "$UPSCALE" -p realesrgan --realesrgan-model realesr-animevideov3 -s "$UPSCALE_FACTOR"

    # ============================================================
    # STEP 3 — HEVC x265 ENCODE (CPU)
    # ============================================================

    echo "--- Step 3: HEVC x265 Encode ---" | tee -a "$LOG"

    nice -n 10 ffmpeg -y -i "$UPSCALE" -map 0:v -c:v libx265 -crf "$X265_CRF" -preset "$X265_PRESET" -pix_fmt yuv420p -x265-params "aq-mode=3:aq-strength=1.0:deblock=-1,-1" "$HEVC"

    # ============================================================
    # STEP 4 — AAC AUDIO CONVERSION
    # ============================================================

    echo "--- Step 4: AAC Audio Conversion ---" | tee -a "$LOG"

    ffmpeg -y -i "$ORIG" -map 0:a? -c:a aac -b:a 192k "$AUDIO"

    # ============================================================
    # STEP 5 — FINAL MKV REBUILD
    # ============================================================

    echo "--- Step 5: Final MKV Rebuild ---" | tee -a "$LOG"

    mkvmerge --engage no_cue_duration --engage no_cue_relative_position -o "$FINAL" --aspect-ratio 0:16/9 "$HEVC" --no-video "$AUDIO" --no-video --no-subtitles "$ORIG" --no-video --no-audio

    # ============================================================
    # STEP 6 — CLEANUP
    # ============================================================

    echo "--- Cleaning Up Intermediates ---" | tee -a "$LOG"

    rm -f "$CFR" "$UPSCALE" "$HEVC" "$AUDIO"

    echo "Completed Successfully: $FINAL" | tee -a "$LOG"

done

# ---------- FINISHED ----------
echo "" | tee -a "$LOG"
echo "==================================================" | tee -a "$LOG"
echo "Batch Complete" | tee -a "$LOG"
date | tee -a "$LOG"
echo "==================================================" | tee -a "$LOG"
